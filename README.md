# Uniq Video — уникализатор MP4-видео

Простая утилита для «уникализации» видео: каждый выходной файл получает свой уникальный «отпечаток» — изменённая картинка, звук и чистые метаданные. Полезно, когда нужно загрузить один и тот же ролик на разные площадки или аккаунты так, чтобы он не определялся как копия.

Утилита написана на **PowerShell** и использует **FFmpeg**. Работает на Windows 10/11. Не требует установки — скачал и запустил.

---

## Что делает

| Параметр | По умолчанию (АВТО) | Настраивается вручную |
|---|---|---|
| Чистка метаданных | всегда (все теги, главы, encoder-метки) | свои теги опционально |
| Случайный ID (`comment=uid:XXXXXXXX`) | всегда | вкл/выкл |
| Питч музыки (незаметно на слух) | 0.97–1.03 | 0.5–2.0 или своё значение |
| Скорость видео+звука | 0.99–1.01 | 0.5–2.0 или своё значение |
| Яркость/контраст/сатурация | случайные ±0.03 | свои значения |
| Рамка | чёрная, 4 px, поверх краёв | тип (поверх/снаружи/нет), толщина, цвет |
| Копий из каждого файла | 1 | 1–100 |
| Журнал CSV с параметрами каждой копии | всегда | — |

Каждая копия получает **свои** случайные значения — два запуска не дают одинаковый результат. С ключом `-Seed` результат воспроизводим.

## Установка

### 1. FFmpeg

Проверьте, установлен ли он: откройте командную строку (Win+R → `cmd`) и введите:

```
ffmpeg -version
```

Если видите версию — переходите к шагу 2. Если «не является внутренней или внешней командой»:

1. Скачайте сборку с официального сайта: https://www.gyan.dev/ffmpeg/builds/ (файл `ffmpeg-release-full.7z`) или с https://github.com/BtbN/FFmpeg-Builds/releases
2. Распакуйте архив, например, в `C:\ffmpeg`
3. Добавьте `C:\ffmpeg\bin` в PATH:
   - Win+R → `sysdm.cpl` → вкладка «Дополнительно» → «Переменные среды»
   - В разделе «Системные переменные» найдите `Path` → «Изменить» → «Создать» → вставьте путь к папке `bin`
   - OK везде, перезапустите командную строку
4. Снова проверьте `ffmpeg -version`

Альтернатива без ручной настройки — через пакетный менеджер (PowerShell от администратора):

```powershell
winget install Gyan.FFmpeg
```

### 2. Скрипт

Скачайте два файла из этого репозитория:

- `Unique-Video.ps1`
- `Unique-Video.bat`

и положите их **в одну папку** (например, `C:\UniqVideo\`). PowerShell уже встроен в Windows — больше ничего ставить не нужно.

> Если Windows блокирует запуск скачанных файлов (ошибка «выполнение сценариев отключено»), разблокируйте: правый клик по `Unique-Video.ps1` → «Свойства» → галочка «Разблокировать» → OK. Обычно достаточно.

## Использование

### Способ 1: двойной клик (самый простой)

1. Скопируйте ваши `.mp4` файлы в папку со скриптом (или запомните путь к ним)
2. Дважды кликните `Unique-Video.bat`
3. Выберите режим:
   - **1 / Enter — АВТО**: обработка сразу, без вопросов, со средними настройками
   - **2 — ВРУЧНУЮ**: пошаговый мастер спросит всё остальное

При старте в консоли первый вопрос:

```
  1. АВТО     — без вопросов, средние настройки, сразу обработка
  2. ВРУЧНУЮ  — пошаговая настройка всех параметров

Режим (1/2) [Enter = 1]:
```

Готовые файлы появятся в папке **`output`** рядом со скриптом + CSV-журнал `uniquelog_ГГГГММДД_ЧЧММСС.csv` с точными параметрами каждой копии.

### Способ 2: из командной строки (для продвинутых)

Откройте командную строку в папке со скриптом. Все параметры можно передать флагами — тогда вопросов не будет вообще:

```bat
:: 3 уникальные копии файла vid.mp4
Unique-Video.bat -Path "C:\видео\vid.mp4" -Count 3

:: обработать все mp4 в папке C:\видео (без рекурсии)
Unique-Video.bat -Path "C:\видео" -Count 1

:: 5 копий каждого файла, рамка снаружи 8 пикселей белая
Unique-Video.bat -Path "C:\видео" -Count 5 -BorderMode pad -BorderWidth 8 -BorderColor white

:: задать питч и громкость вручную (0.98 = тон ниже, 0.9 = тише)
Unique-Video.bat -Pitch 0.98 -Volume 0.9

:: микро-ускорение видео и звука на 2%
Unique-Video.bat -Speed 1.02

:: тестовый прогон — покажет команды ffmpeg, ничего не выполняя
Unique-Video.bat -DryRun

:: повторяемый результат (одинаковые значения при том же seed)
Unique-Video.bat -Seed 42

:: вся справка по параметрам
Unique-Video.bat -Help
```

### Справочник параметров

| Параметр | По умолчанию | Описание |
|---|---|---|
| `-Path` | текущая папка | файл или папка с `.mp4` |
| `-OutDir` | `output` | папка вывода |
| `-Count` | 1 | сколько копий делать из каждого файла |
| `-BorderMode` | `drawbox` | `drawbox` (рамка поверх, разрешение не меняется) / `pad` (снаружи, разрешение растёт) / `none` |
| `-BorderWidth` | 4 | толщина рамки, пиксели |
| `-BorderColor` | `black` | цвет: `black`, `white`, `red`, `0xRRGGBB` |
| `-Pitch` | 0 (случайный) | питч звука: <1 — ниже, >1 — выше, 1 — без изменения |
| `-PitchMin` / `-PitchMax` | 0.97 / 1.03 | диапазон случайного питча |
| `-Volume` | 1.0 | громкость (0.9 = −10%) |
| `-Speed` | 0 (случайная) | скорость: >1 — быстрее, <1 — медленнее |
| `-SpeedMin` / `-SpeedMax` | 0.99 / 1.01 | диапазон случайной скорости |
| `-Brightness` | случайная | −1…1 (0.02 = чуть светлее) |
| `-Contrast` | случайный | 1.0 = без изменения |
| `-Saturation` | случайная | 1.0 = без изменения |
| `-EqJitter` | 0.03 | сила случайного разброса картинки (0 = выкл) |
| `-CRF` | 18 | качество x264: меньше = лучше и тяжелее (14–28 разумный диапазон) |
| `-Preset` | `medium` | скорость кодирования: `ultrafast`…`slow` |
| `-Suffix` | `_uniq` | суффикс имён файлов |
| `-Tags` | пусто | свои теги: `-Tags "title=Моё видео,author=Я"` |
| `-RandomTag` | выкл | вписать случайный `comment=uid:...` |
| `-Recurse` | выкл | искать mp4 во вложенных папках |
| `-Seed` | случайный | фиксирует случайность для воспроизводимости |
| `-DryRun` | выкл | показать команды, ничего не делать |
| `-Help` | — | справка |

## Как работает «уникализация» изнутри

Скрипт собирает ffmpeg-команду из нескольких фильтров:

1. **Метаданные** — `-map_metadata -1 -map_chapters -1` вычищает все теги и главы; `-fflags +bitexact` убирает метку кодировщика `encoder=Lavf...`. Опционально вписывается свежий случайный `comment=uid:XXXXXXXX`.
2. **Видео**: `eq` (яркость/контраст/сатурация) → `setpts` (скорость) → `drawbox` или `pad` (рамка). Если все фильтры выключены — поток копируется без перекодирования.
3. **Аудио**: `asetrate` + `aresample` + `atempo` — сдвиг высоты тона без изменения длительности, затем `atempo` для скорости и `volume` для громкости.
4. **Кодирование**: `libx264` (CRF + preset), `aac` 192k, `-movflags +faststart` для быстрого старта воспроизведения в интернете.

Питч и цветокоррекция выбраны в диапазонах, которые на глаз и на слух незаметны, но меняют контрольные суммы кадров и звукового потока — то, по чему платформы сравнивают видео.

## Частые вопросы

**Выходное видео теряет качество?**
При CRF 18 изменения практически незаметны. Можете поставить `-CRF 14` для почти оригинального качества (файл будет тяжелее) или `-CRF 23` для меньшего размера.

**Почему файл стал больше/меньше оригинала?**
Размер зависит от CRF и пресета. Оригинал мог быть закодирован с другим качеством — это нормально.

**Рамка не нужна, но нужна уникализация**
`-BorderMode none` — рамки не будет, а питч/цвет/скорость останутся.

**Что если в видео нет звука?**
Скрипт сам определяет это и обрабатывает только видео.

**Видео 321×241 (нечётные размеры)**
Поддерживается — скрипт автоматически выравнивает размеры до чётных (для кодека H.264 это требование).

**Антивирус ругается на .ps1?**
Это ложное срабатывание на скрипты PowerShell — код открыт, можете прочитать его целиком. При необходимости запустите через `powershell -ExecutionPolicy Bypass -File Unique-Video.ps1`.

**Нужны старые версии Windows?**
Windows 10/11 — из коробки. На Windows 7/8 нужен PowerShell 5.1 (обычно есть) и ручная установка FFmpeg.
